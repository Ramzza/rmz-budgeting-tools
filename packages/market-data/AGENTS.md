# AGENTS.md

## Project context
`rmz-market-data` is a TypeScript library and CLI for Yahoo Finance stock/ETF prices and CursBNR RON exchange rates; see [README.md](README.md).
- `src/` contains the shared library, provider integrations, date/error handling, and CLI.
- `tests/` contains TypeScript tests, including executable PRD requirement mappings.
- The repository root `.github/` contains shared Copilot instructions and CI workflows.
See [ARCHITECTURE.md](ARCHITECTURE.md) for module flow and the [root PRD](../../PRD.md) for product requirements.

## Conventions
- Use Node.js 22+ and TypeScript targeting ES2022/NodeNext with strict checking (`tsconfig.json`).
- Follow [ARCHITECTURE.md](ARCHITECTURE.md): `src/index.ts` owns public exports; `src/cli.ts` owns commands and JSON/CSV serialization; `src/prices.ts` and `src/bnr.ts` own provider integrations; `src/dates.ts` parses dates; `src/errors.ts` defines `MarketDataError`.
- Reuse `MarketDataError` for invalid input and CursBNR source failures; Yahoo Finance client errors propagate.
- No repository linter or formatter is configured.

## Scripts
- `npm run build` compiles TypeScript into `dist/` and makes the CLI executable.
- `npm test` runs `node --import tsx --test tests/*.test.ts`.
- `npm start --` runs the compiled CLI; build first.
- The root CI workflow uses Node 22, installs root and package locks, then runs `npm run build` and `npm test` (`../../.github/workflows/build-test.yml`).

## Constraints
- Before behavior changes, read the [root PRD](../../PRD.md) and follow the root Copilot instructions; map every stable requirement to an executable test, and prove new or updated behavior tests fail before changing production code (use a controlled mutation if behavior already exists).
- Read `ARCHITECTURE.md` before changing module boundaries.
- Edit `src/`, not `dist/`; `dist/` is generated by the build and ignored by Git.
- Preserve inclusive date ranges, exact-date/missing-rate behavior, and CursBNR HUF-per-100 normalization from the [root PRD](../../PRD.md); fetching requires network access and results are not cached or persisted.
